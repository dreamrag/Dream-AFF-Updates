# Genni APK releases

This repository distributes the current Genni APK and its release metadata. The latest release also includes the complete source snapshot that matches that APK.

Use the source ZIP attached to the latest release tag; it is the version-matched source of record. Older source ZIP assets are retired when superseded to prevent selecting a mismatched source version. Historical APK releases and their manifests remain available.

Latest release: https://github.com/dreamrag/Dream-AFF-Updates/releases/latest
